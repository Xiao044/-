## 1. 当前阶段

**V2.0 开发与手动验收，尚未达到正式产品发布门槛。** 知识库 R1a/R1b、备份恢复专项和 V3.0 继续后置。

本轮按 `dev-workflow` 实现并审查 R2/R3/R4：复用现有 DS A → 独立网页文字模型任务 → B 候选 → 显式应用/严格确认 → 另行发送生图。豆包和 ChatGPT 可选，指的是用户网页**当前页面模型**，不声称自动识别或切换精确模型。知识增强尚未实现。

## 2. 已有与缺失

| 模块 | 当前实现 | 验收边界 |
|---|---|---|
| DS 文字 Agent | 追问、A 生成、事实规则、历史与编辑确认、取消/重试保护 | 复用底座；本轮不调用真实 DS，不包含知识库 |
| 知识库 | 无条目、检索或知识增强服务 | 框架和内容均已后置，用户后续收集 |
| R2 网页文字任务 | `/text-jobs`、服务器拥有的 `project.textWorkflow`、A 快照/指纹/run/version、单次 dispatch、事件、重试/取消/超时/恢复 | 隔离 API/并发/导入/恢复回归通过；不自动重复提交 |
| R3 文字模型与回读 | 豆包/ChatGPT 专用文字 adapter，独立选择，完成证据＋稳定文本，原始回复与可编辑候选 | 目前实验性；真实网页/账户与 Chrome/Edge 矩阵未验收 |
| R4 B 确认与生图 | 候选显式应用；严格保存成功才提交确认；确认不自动生图；最终发送只用确认 B | 本地行为、HTTP 与隔离浏览器验证；旧手填/模板兼容保留 |
| 图片任务与资产 | 保留版本/任务/资产/模板/导出；豆包原图/SVG过滤与同尺寸合并 | 完整真实平台结果/归档矩阵和 ZIP 浏览器下载仍有未验收项 |
| 旧项目与替换 | 普通 PUT 保护文字历史，A/平台/导入/版本替换失效旧任务与候选 | 原手工/模板来源不伪造；改建兼容和旧回归通过 |
| V3.0 | 尚未实现 | MySQL/OSS、账号权限、协作/审计与正式云部署后置 |

## 3. 本轮版本与发布方式

- 源码、manifest、工作台与适配器门槛统一为 **0.5.1**，包含此前 0.4.4 原图过滤/精确发送修复和本轮审查修正。
- 本记录在发布检查前冻结；提交/推送是否成功、最终 SHA 以本轮 Git 交付回执为准，不预写成功状态。目标仍为现有 `origin/main`，不强推、不另开 PR。
- **使用时需重启 Node 后端**以加载新 API，再重载扩展并刷新工作台及平台页面。仅刷新网页不会升级已运行的旧进程。
- 协调员没有重启用户原有 5173 服务，也没有修改真实 `.env`、data 或上传。浏览器 QA 全部使用独立临时数据、合成 A/B 和模拟文字桥接，无真实模型或图片发送。
